# MathSheetPress

Build math worksheet books whose **answer keys are proven, not printed from generator state**.

## Why

Every teacher knows the free-worksheet failure mode: problem 14's answer in the key belongs to a different problem, or the key was generated by the same code that wrote the question — so one bug poisons both. MathSheetPress generates each problem by construction (pick the answer, build the question around it), then **re-solves every problem a second way** before printing: arithmetic is re-read by an independent expression evaluator, equations are re-solved with exact Fraction algebra, quadratics are re-factored by an integer root search. The answer key is written from the *second* solve. If the two paths disagree, the problem is rejected and never appears. A worksheet book contains **zero duplicate questions**.

## Use

**App (Windows):** launch `MathSheetPress.exe`, choose worksheet count, problems per sheet, band and seed, click **Build the book**. Output: `mathsheet_book.pdf` in a `mathsheetpress_out` folder — title page, worksheet pages with name/date header lines and work space, then a compact answer key section. 8.5×11in (612×792pt).

**Command line:** `python math_sheet.py out/ --worksheets=10 --per-sheet=20 --band=Mixed --seed=42`

A sample book is included (`sample_book.pdf`).

## Bands & topics (14 generators)

- **Arithmetic** — multiplication, division, fraction addition, percent-of, order of operations
- **Pre-Algebra** — integer operations, one-step equations, two-step equations, proportions, exponents
- **Algebra** — two-sided linear equations, slope from two points, factoring quadratics, 2×2 systems (plus two-step equations)
- **Mixed** — all of the above

## Verified

Acceptance test (9/9 PASS, `test/acceptance_results.txt`): a 4-sheet × 12-problem mixed book — every printed answer re-derived by the verifier (48/48), expression problems additionally re-evaluated by a third path with zero disagreements, one deliberately corrupted answer flagged by the gate (exactly 1), zero duplicate questions book-wide, PDF exactly 612×792pt, deterministic for a fixed seed, Arithmetic band stays in-band.

## Scope

Problems use integer/fraction arithmetic with exact answers (no rounding drift). Deterministic seeds make re-issues and answer-key regeneration repeatable. 100% local — no uploads, no accounts, no per-book fees.

## Build from source

`pip install pyinstaller reportlab`, then `pyinstaller mathsheetpress.spec`. Or push to GitHub and let the included Actions workflow build the Windows package.
